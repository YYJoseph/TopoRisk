# Contributing

Issues and pull requests are welcome for reproducibility fixes, additional
baselines, graph families, and verifier-allocation analyses.

Before opening a pull request:

1. run `make test`;
2. run `make verify`;
3. do not commit credentials, `.env` files, raw provider conversations, or
   benchmark records without verified redistribution permission; and
4. describe any change to reported aggregate values explicitly.

The repository is a research preview. Please keep claims within the scope of
the packaged evidence and do not describe the artifacts as a production safety
certification.
